# Drawer Detail
## Prerequisites
- Have mastery of `drawer` for opening and closing via actions.
- Define row components (`component CustomerRow`) with `%props`.
- Know `list $Component:` to feed the drawer with dynamic data.

## Step-by-step
1. Create a row component (`CustomerRow`) with a CTA that opens the drawer.
2. Declare the `drawer CustomerDetail` receiving props like name, company, and last contact.
3. Feed the main list with `list $CustomerRow:` using values separated by `|`.
4. Add internal actions (follow-up, close) inside the drawer to keep the flow complete.

<DocsCodePreview title="Complete flow of list + detail drawer">
```dsl
component InfoRow:
  row-between:
    >> %label
    >>> %value

drawer CustomerDetail:
  container:
    # %name
    >> %company
    >>> Last contact: %lastContact

    list $InfoRow:
      - Status | In negotiation
      - Estimated value | $180K
      - Next step | Present final proposal

    card:
      ## Notes
      > Update the CRM after the meeting.

    row-end:
      @ghost[Close](close)
      @success[Schedule follow-up](scheduleFollowUp)

component CustomerRow:
  card-compact:
    row-between:
      stack-tight:
        ## %name
        >>> %company
        >>> Last contact: %lastContact
      @ghost[i-ChevronRight View details](CustomerDetail)

screen Accounts:
  container:
    # Strategic accounts
    list $CustomerRow:
      - Ana Souza | Proto Labs | Yesterday
      - Bruno Lima | NextWave | 3 days ago
      - Carla Dias | FutureSoft | 7 days ago
```
</DocsCodePreview>
Why: keeps the main list visible while the drawer displays details and contextual actions.

## Quick debugging
- Drawer not opening → check if the CTA points to `CustomerDetail` exactly.
- Props not appearing → validate the order of values in the list rows.
- Internal actions not closing → use `@ghost[Close](close)` or `@ghost[Cancel](close)`.
- Content overflow → apply `container` or `stack` inside the drawer to control spacing.
- List with inline actions → move buttons inside the component or to `row-end`.
