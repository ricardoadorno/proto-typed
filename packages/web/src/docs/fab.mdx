# Floating Action Button (FAB)
The FAB keeps a global action always available, floating above the content to speed up recurring tasks.

## When to use
- Highlight the most frequent action on the screen in mobile or responsive scenarios.
- Offer global shortcuts, such as creating records or opening relevant filters.
- Complement dashboards and lists when the main CTA does not fit in the header.
- Activate quick drawers or modals without losing the current context.

## Basic example
<DocsCodePreview title="FAB with a single main action">
```dsl
screen Tasks:
  container:
    # Tasks
    list:
      - Review backlog
      - Prepare release

  fab{plus}(TaskForm)
```
</DocsCodePreview>
Why: keeps task creation within reach without competing with the screen content.

<DocsCodePreview title="FAB triggering a confirmation modal">
```dsl
screen Default:
  container:
    # Scroll down to see

  fab{check}(ConfirmRelease)

modal ConfirmRelease:
  card:
    ## Publish release?
    > Confirm to notify the team.
    row-end:
      @ghost[Cancel](close)
      @success[Publish](publishRelease)
```
</DocsCodePreview>
When to use: reinforce global actions that need confirmation before executing.
Why: avoids irreversible executions by interspersing immediate feedback.

<DocsCodePreview title="FAB opening a contextual drawer">
```dsl
screen Default:
  container:
    > Scroll down to see

  fab{filter}(FilterDrawer)

drawer FilterDrawer:
  container:
    # Advanced filters
    ___[Status][Select status[All | In progress | Completed]]
    row-end:
      @ghost[Cancel](close)
      @[Apply](applyFilters)
```
</DocsCodePreview>
When to use: expose quick adjustments while keeping the main data visible.
Why: the drawer allows inline adjustments without changing the screen.

## Composition (using with others)
- **FAB + Main button** — fixed CTA coexists with local actions in cards.
- **FAB + Drawer** — opens filters or details without redirecting.
- **FAB + Modal** — validates critical commands before proceeding.


## Slots & Props
| Name | Type | Default | Description | Required |
| --- | --- | --- | --- | --- |
| `icon` | string `{iconname}` | — | Icon displayed on the floating button. | Yes |
| `destination` | slug/action | — | Screen, modal, or drawer opened on touch. | Yes |

## Common errors (Do/Don't)
<DoDont
  dont={{
    title: "Duplicate CTA",
    code: `
screen Tasks:
  header:
    @[New task](TaskForm)

  fab{plus}(TaskForm)
    `,
  }}
  do={{
    title: "Complementary CTA",
    code: `
screen Tasks:
  header:
    @[New task](TaskForm)

  fab{filter}(FilterDrawer)
    `,
  }}
>
  Why: the FAB should add extra value, not duplicate the already available CTA.
</DoDont>
<DoDont
  dont={{
    title: "FAB for unrelated action",
    code: `
screen Tasks:
  container:
    # Task list

  fab{settings}(ThemeDrawer)
    `,
  }}
  do={{
    title: "FAB for main screen action",
    code: `
screen Tasks:
  container:
    # Task list

  fab{plus}(TaskForm)
    `,
  }}
>
  Why: the FAB should provide the most relevant action for the screen context.
</DoDont>
