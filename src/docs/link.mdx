# Link
Links criam navegação inline para telas, modais ou URLs externas sem quebrar o fluxo de leitura.

**Nova sintaxe (v0.0.2)**:
- `@core[Texto](Destino)` — navegação interna (telas, modais, drawers)
- `@web[Texto](URL)` — links externos (abre em nova aba)

## Quando usar
- Referenciar telas ou recursos secundários dentro de parágrafos e listas.
- Direcionar para artigos, e-mails ou telefones externos ao ambiente Proto-Typed.
- Oferecer caminhos alternativos enquanto o CTA principal permanece em botões.
- Conectar seções relacionadas quando um `navigator` não é necessário.

## Exemplo básico
<DocsCodePreview title="Links em texto de suporte">
```dsl
screen HelpCenter:
  container:
    # Central de ajuda
    > Consulte a @web[documentação oficial](https://proto-typed.dev/docs) para um panorama completo.

    card:
      ## Precisa redefinir senha?
      >> Acesse a @core[tela de recuperação](RecoverPassword) e siga os passos.
```
</DocsCodePreview>
Por quê: mantém a leitura fluida e oferece navegação contextual com semântica clara entre links internos e externos.

## Variantes
<DocsCodePreview title="Link interno para screen (@core)">
```dsl
screen Default:
  container:
    @core[Ver detalhes](DetailScreen)
```
</DocsCodePreview>
Quando usar: apontar para telas, modais ou drawers existentes no fluxo.
Por quê: `@core` indica navegação interna SPA sem recarregar a página.

<DocsCodePreview title="Link externo (@web)">
```dsl
screen Default:
  container:
    @web[Abrir documentação](https://proto-typed.dev/docs)
```
</DocsCodePreview>
Quando usar: referenciar recursos hospedados fora do produto.
Por quê: `@web` abre em nova aba com `target="_blank"` e segurança `rel="noopener noreferrer"`.


## Composição (usando com outros)
- **Link + Card** — oferece contextos adicionais dentro de blocos informativos.
- **Link + List** — transforma itens em atalhos sem necessidade de botões.
- **Link + Drawer** — agrupa links em painéis laterais de referência.

<DocsCodePreview title="Drawer com links rápidos">
```dsl
drawer QuickLinks:
  container:
    # Links rápidos
    stack-tight:
      @core[Dashboard](Dashboard)
      @core[Equipe](Team)
      @core[Configurações](Settings)

screen HeaderDemo:
  header:
    # Proto-Typed
    row-end:
      @[Abrir links rápidos](QuickLinks)
```
</DocsCodePreview>
Por quê: agrupa atalhos de navegação interna sem sobrecarregar o cabeçalho com botões.

## Slots & Props
| Nome | Tipo | Padrão | Descrição | Obrigatório |
| --- | --- | --- | --- | --- |
| `variante` | enum (`@core`, `@web`) | `@core` | Define se é navegação interna ou link externo. | Sim |
| `label` | string | — | Texto exibido entre `[ ]`. | Sim |
| `destino` | slug ou URL | — | Tela, modal, drawer ou endereço externo (URL completa para `@web`). | Sim |

## Erros comuns (Do/Don't)
<DoDont
  dont={{
    title: "Usar botão para navegação simples",
    code: `
@[Ver detalhes](DetailScreen)
    `,
  }}
  do={{
    title: "Usar link para navegação inline",
    code: `
@core[Ver detalhes](DetailScreen)
    `,
  }}
>
  Por quê: Links são para navegação inline em parágrafos; botões para CTAs destacados.
</DoDont>
<DoDont
  dont={{
    title: "Usar @core para URL externa",
    code: `
@core[Documentação](https://docs.example.com)
    `,
  }}
  do={{
    title: "Usar @web para URL externa",
    code: `
@web[Documentação](https://docs.example.com)
    `,
  }}
>
  Por quê: `@web` abre em nova aba e aplica segurança adequada para links externos.
</DoDont>
<DoDont
  dont={{
    title: "Link sem destino",
    code: `
@core[Leia mais]()
    `,
  }}
  do={{
    title: "Destino declarado",
    code: `
@core[Leia mais](Guides)
    `,
  }}
>
  Por quê: cada link precisa apontar para um destino existente para evitar erros de navegação.
</DoDont>

## Referências cruzadas

### Relacionados
- [`Button`](./button): ações que executam lógica ou abrem fluxos.
- [`Navigator`](./navigator): navegação estruturada por abas ou menus.
- [`Drawer`](./drawer): agrupa links de referência lateralmente.
- [`Screen`](./screen): destino mais comum para links internos.

### Composições recomendadas
- **Link + Card** → blocos informativos com referências adicionais.
- **Link + List** → coleções de atalhos sem usar botões.
- **Link + Drawer** → catálogos laterais de documentação ou suporte.
